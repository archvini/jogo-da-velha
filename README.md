# Jogo da Velha

Jogo da velha para jogar contra o computador ou desafiar outra pessoa no mesmo navegador. Feito com HTML, CSS e JavaScript puro, sem bibliotecas.

![Ilustracao do jogo da velha com placar e tabuleiro](assets/jogo-da-velha.svg)

## Como jogar

Abra o `index.html` no navegador e clique nas casas, alternando entre X e O.

- Por padrão, voce joga de X contra o computador (O). Desmarque a opção no topo para jogar com outra pessoa.
- O computador usa minimax, mas erra de propósito em 20% das jogadas para dar para ganhar.
- Três iguais em linha, coluna ou diagonal vencem.
- O placar guarda vitórias de X, de O e empates enquanto a página estiver aberta.
- Quem começa alterna a cada partida.
